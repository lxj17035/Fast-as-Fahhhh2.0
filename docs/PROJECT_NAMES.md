# Project name suggestions

Team: Fast as Fahhhhh. Final product name is not selected yet; the README uses QuoteFlow as a provisional working title pending team discussion.

| Name | Why it fits |
| --- | --- |
| **QuoteFlow** (recommended) | Clearly describes moving an enquiry through drafting, review, and quotation delivery. Easy to explain in a pitch. |
| EnquiryFlow | Emphasizes capturing and following up customer enquiries; leaves room for features beyond quotations. |
| QuoteBridge | Connects customer messages, business information, and PM review. |
| ReplyReady | Emphasizes preparing a response while keeping a person in control of sending. |

Suggested pitch line for QuoteFlow: “From customer enquiry to a reviewed quotation, with less busywork.”

These are naming ideas, not a final naming decision. Team identity and product identity are separate: Fast as Fahhhhh is the team name.
